首先照抄一下开源社的啾叽  
  先按 Windows logo 键 + X 打开快捷菜单，再按英文 I 键打开 Windows 命令行终端，最后输入两条命令即可完成 DeepSeek 安装、启动：
```bash
winget install Ollama.Ollama
ollama run deepseek-r1:7b
```
ollama 挺好的，开搞！
